# frontend-study

프론트엔드 공부를 하면서 만든 예제, 작은 프로젝트, 실험 코드를 한곳에 모아두는 저장소입니다.

처음 배울 때 만든 코드부터, 나중에 다시 참고하고 싶은 실습 코드까지 주제별로 정리합니다.  
완성된 포트폴리오보다는 **학습 과정과 반복해서 꺼내 볼 수 있는 예제**에 더 가깝습니다.

## 이 저장소의 목적

프론트엔드를 공부하다 보면 작은 예제가 계속 생깁니다.

처음에는 각각의 레포지토리로 관리해도 괜찮지만, 시간이 지나면 비슷한 성격의 저장소가 많아지고 다시 찾기도 어려워집니다.  
이 저장소는 그런 학습 자료를 하나의 흐름으로 정리하기 위해 만들었습니다.

- 예전에 만든 예제를 버리지 않고 정리하기
- 주제별로 다시 찾아보기 쉽게 만들기
- 학습 과정과 성장 흔적을 남기기
- 실무에서 다시 쓸 수 있는 작은 코드 조각을 모아두기

## 분류 기준

### animation

CSS 애니메이션, 인터랙션 효과, 움직임 표현을 실험한 예제를 모아둡니다.

| 폴더 | 내용 |
|---|---|
| `css-effect/` | CSS로 만든 시각 효과와 인터랙션 실험 |
| `animate/` | 애니메이션 구현 방식 실습 |
| `animate-css/` | animate.css 또는 유사한 애니메이션 라이브러리 학습 |

### javascript

순수 JavaScript로 만든 작은 기능과 미니 프로젝트를 정리합니다.

| 폴더 | 내용 |
|---|---|
| `dice-game/` | 주사위 게임 예제 |
| `draw-paint-js/` | 캔버스 또는 DOM을 활용한 그리기 예제 |

### react

React를 공부하면서 만든 예제와 작은 프로젝트를 정리합니다.

| 폴더 | 내용 |
|---|---|
| `react-coin-list/` | API 데이터, 리스트 렌더링, 상태 관리를 연습한 예제 |

### svelte

Svelte를 학습하면서 만든 예제를 정리합니다.

| 폴더 | 내용 |
|---|---|
| `svelte-todo/` | Svelte 기본 문법과 상태 처리를 연습한 Todo 예제 |

### study-list

공부할 내용, 참고 자료, 학습 흐름을 정리합니다.

| 폴더 | 내용 |
|---|---|
| `study-list/` | 학습 목록, 참고 링크, 공부 계획 정리 |

## 학습 기록

각 예제 폴더에는 가능한 한 간단한 README를 함께 둡니다.

권장 형식은 아래와 같습니다.

```md
# 예제 이름

## 학습한 내용

- 무엇을 만들었는지
- 어떤 개념을 연습했는지
- 다시 볼 때 확인해야 할 포인트

## 실행 방법

```bash
npm install
npm run dev
```

## 메모

- 작업하면서 막혔던 부분
- 다음에 개선하고 싶은 부분
```

완성도가 낮은 예제라도 괜찮습니다.  
다만 나중에 다시 열었을 때 “무엇을 공부하려고 만든 코드였는지”는 알 수 있게 남기는 것을 목표로 합니다.

## 정리 원칙

이 저장소는 무조건 예쁜 코드만 모아두는 곳이 아닙니다.

공부하면서 만든 코드는 당연히 부족할 수 있습니다.  
중요한 건 부족한 코드를 남기는 것이 아니라, 그때 무엇을 배웠고 다음에 무엇을 고치면 좋을지 기록하는 것입니다.

정리할 때는 아래 기준을 따릅니다.

- 주제별 폴더를 먼저 정하고 그 안에 예제를 넣기
- 한 예제는 하나의 폴더로 관리하기
- 불필요한 `node_modules`, `dist`, `.env` 파일은 올리지 않기
- 예제별 README에는 학습 목적과 실행 방법을 짧게 남기기
- 오래된 예제라도 의미가 있으면 삭제하지 않고 현재 기준의 메모를 추가하기
